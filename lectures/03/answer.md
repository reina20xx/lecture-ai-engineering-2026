# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素のLLMはモデルの知識だけで回答するため、講座固有の「3レベル」を正確に説明できるとは限らない。エージェントは `search_glossary` で用語集を調べ、その定義に基づいて回答する。
- `--trace` で見えたツール呼び出し（ツール名と引数）：`search_glossary(query="LoRA")` と `search_glossary(query="QLoRA")`。用語を1つずつ検索し、返ってきた定義を使って違いを回答する。
- 1つの質問での LLM 呼び出し回数（`requests`）：2回（ツール呼び出しの判断と、ツールの結果を受けた回答）。
- 追加したツールと、docstring に書いた説明：`make_quiz(lecture: int)` を追加してエージェントに登録した。「指定した回の用語から確認問題を1問作り、答えを返す。利用者が講義内容の問題を求めたときに使う」と説明し、指定回の用語をランダムに1つ選んで、その意味を答えとして返す。

## 宿題

- 取り組んだレベル：基礎
- やったこと：`app/agent.py` の `INSTRUCTIONS` と `app/tools.py` の `search_glossary` の docstring を変更し、一般的な用語同士の比較では検索せず、用語の定義や講座固有の質問では検索するようにした。同じ質問「LoRAとQLoRAの違いは？」を変更前後で `--trace` 付きで実行した。
- 結果：変更前は `search_glossary(query="LoRA")` と `search_glossary(query="QLoRA")` が呼ばれ、`requests=2` だった。変更後はツール呼び出しがなくなり、`requests=1` になった。変更前は用語集に基づいて関連回を第2回と回答したが、変更後は第5回と誤って回答した。
- 気づき・疑問：指示や docstring の書き方でツールの呼ばれ方と回答が変わる。検索を省くと呼び出し回数は減る一方、講座固有の情報を参照できず、関連回のような事実を誤ることがある。
